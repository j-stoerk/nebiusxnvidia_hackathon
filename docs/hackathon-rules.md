## Eligibility and legal review

Adults; individuals, teams, organizations. Appoint a representative. Excluded: Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea, sanctioned/prohibited jurisdictions; organizers, judges, related employers/affiliates/families/households and conflicts (§3). No purchase required.

Own original contributions; respect third-party licenses/privacy; disclose significant work since August 26 for preexisting projects. Distinct multiple entries allowed. Preferential sponsor/administrator development support can disqualify (§4).

Free judging access through December 15; provide credentials if needed. English or translations. Freeze submission after deadline; only organizer-approved corrections (§§4–5).

Equal judging weights; ties follow criterion order, then panel vote (§6). Ownership retained; judging license and promotional permissions apply (§7).

Awards: $20k/$10k/$6k overall; four Jetson track awards; Tavily $3k; twenty $500 city awards; ten $100 feedback awards plus swag. Prize combinations restricted to one overall OR track, plus one bonus. Identity verification, ten-business-day forms, taxes/fees apply (§8).

Binding entry terms include releases, publicity, organizer changes/disqualification, liability limits, individual arbitration/New York law, incorporated Devpost terms, and privacy policy (§§9–15). Read linked sections before entry; request organizer clarification for ambiguity. Official rules prevail over other pages (§11).

Source: [rules, all fifteen sections](https://nebiusglobalaihackathon.devpost.com/rules).

For the Tavily bonus, a functional runtime Tavily API call is required; citing it as a development aid does not qualify (§8).

## ChargeWise submission checklist

- [ ] Choose **Best Apps and Agents**; deploy working charging operations software.
- [ ] Run NVIDIA Nemotron through Nebius Token Factory; document the actual model and integration.
- [ ] Submit an English description explaining audience, functionality, and implementation.
- [ ] Provide a working demo/test URL.
- [ ] Make the repository public with a detectable open-source license, complete source, assets, setup, and run instructions.
- [ ] Record a public YouTube demo under three minutes showing the running app and Nebius/NVIDIA usage.
- [ ] Submit feedback on the technologies used.
- [ ] Explain significant in-period updates if the project predates the competition.

Evaluation areas: implementation, design, demonstrated impact, and originality. Other tracks: coding/engineering, personal AI, physical AI. Physical AI has a one-minute operating-module/hardware footage condition and a demo URL exception.

Source: [overview and submission requirements](https://nebiusglobalaihackathon.devpost.com/).

## Infrastructure and credits

A runtime NVIDIA model call through Token Factory qualifies; unrelated frontend/backend hosting can be elsewhere. Another inference provider alone does not qualify. Team size is unlimited. City awards require in-person attendance. Account provisioning limitations differ from competition eligibility; contact Nebius for access problems. Source: [FAQ](https://nebiusglobalaihackathon.devpost.com/details/faqs).
